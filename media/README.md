# Media — Wobble Haul

All images and videos here were rendered by the game itself (the real three.js renderer, models and simulation) using `scripts/capture.mjs`. Nothing was painted, generated by an external tool, or edited by hand. Regenerate with:

```bash
npx vite build --mode capture          # capture build -> dist-capture/ (dev tools on + capture hooks + preserveDrawingBuffer; never shipped)
node scripts/capture.mjs covers        # 3 covers
node scripts/capture.mjs video landscape
node scripts/capture.mjs video portrait
```
Rendering ran in headless Chromium with SwiftShader (software GL) at the **High** preset. The capture build is not shipped; the upload ZIP is built from `dist/`.

## Preview videos
VIDEO_TABLE

How they are made:
- Three clips of **real gameplay** (Harbor 6, Canyon 7, Midnight 4) driven by the scripted test driver (`src/sim/autopilot.ts`, the same one the unit tests use). Before each clip the run is simulated (not recorded) to an interesting stretch, so the clip starts mid-level.
- Each video frame advances the game's own clock by exactly 1/30 s and renders, so the footage plays at **real game speed** (no fast-forward, no slow-motion added; the game's own short slow-motion "shed" teaching moments only occur in the tutorial, which is not used).
- Normal in-game follow camera. HUD hidden. No cursor. Hard cuts between clips; no transitions, logos, captions or promo text.
- **First frame is the matching cover** (2 frames at 30 fps; the 2:3 video uses the 800×1200 cover scaled to 1080×1620).
- No audio track (`-an`). H.264, yuv420p, CRF 18, `+faststart`.

Owner checks:
- 2:3 at "1080p" was interpreted as **1080×1620**. Confirm against the portal's upload form.
- The driver is a bot. It plays cleanly but cautiously; a recording of a skilled human run may show off the wobble better.
